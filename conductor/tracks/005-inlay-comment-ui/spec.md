# Specification: 005-inlay-comment-ui

## 1. 概要 (Overview)
GitHub Issue #5 に基づき、エディタ内で直接レビューノートを追加・表示・編集するためのインライン UI コンポーネントを実装します。
ガターアイコン等のクリックにより表示される入力フォーム `CommentInputPanel` と、保存されたコメントを行の下に常時表示する `CommentBlockRenderer` (Inlay) を提供し、直感的なレビューノート作成体験を実現します。

## 2. 機能要件 (Functional Requirements)

### 2.1 CommentInputPanel (入力フォーム) の実装
- **UIコンポーネント**: `JPanel` ベースで作成。
- **入力フィールド**: コメント内容を入力・編集するための `JTextArea`。複数行入力に対応。
- **操作ボタン**:
  - **Save (保存)**: 入力内容を確定し、保存処理を呼び出す。
  - **Cancel (キャンセル)**: 編集を破棄して閉じる。
  - **Delete (削除)**: 既存コメントの場合はコメントを削除する（新規作成時は非表示または無効）。
- **コールバック通知**: 入力完了（保存）、キャンセル、削除の各イベントを親コンポーネントまたはサービスに通知するコールバックインターフェース（または Kotlin のラムダ）を持つ。

### 2.2 CommentBlockRenderer (Inlay表示) の実装
- **表示方法**: IntelliJ の `InlayModel.addBlockElement` を使用し、対象行の真下にブロック要素としてインライン挿入する。
- **ビジュアルスタイル**:
  - IntelliJ の標準スタイルに準拠。
  - 薄い背景色、極細の境界線（枠線）、丸角ボックスでの描画。
  - エディタの標準フォントおよび色設定（Scheme）に適応。
- **再編集トリガー**:
  - 表示されている Inlay ブロック領域をシングルクリックすることで、その場で入力パネル（`CommentInputPanel`）に切り替わる動作とする。

### 2.3 入力パネルと Inlay 表示の連携 (Interaction Flow)
- **新規作成**:
  - ガターアイコン等をクリックすると、該当行 of 真下に入力パネル（`CommentInputPanel`）を Inlay として挿入して開く。
- **保存処理**:
  - `CommentInputPanel` で「Save」が押された際、コールバックを介してローカルのJSONストレージへ即座に永続化処理を要求する。
  - 入力パネルの Inlay を破棄し、静的なコメントテキスト表示を行う `CommentBlockRenderer` の Inlay に置き換える。
- **キャンセル処理**:
  - 新規作成時：入力パネルを破棄し、Inlay をエディタから削除する。
  - 再編集時：編集中の入力パネルを破棄し、元の静的コメント表示 Inlay に戻す。
- **削除処理**:
  - `CommentInputPanel` で「Delete」が押された際、コールバックを介してストレージからコメントを削除し、Inlay をエディタから完全に除去する。

## 3. 非機能要件 (Non-Functional Requirements)
- **スレッド管理**: UI の生成・破棄、Inlay への追加・削除はすべて EDT (Event Dispatch Thread) 上で安全に実行されること。
- **レイアウト崩れ防止**: エディタのフォントサイズ変更やウィンドウサイズ変更時に、Inlay 描画幅が正しく計算されること。

## 4. 受入基準 (Acceptance Criteria)
- ガター領域のアクションなどからトリガーして、指定行の下に入力パネルが展開されること。
- 入力パネルにテキストを打ち込み「Save」を押すと、入力パネルが消え、同じ場所に入力されたテキストが丸角ボックスで表示されること。
- 表示されたコメントをシングルクリックすると、即座に編集中の入力パネルに切り替わること。
- 「Delete」を押すと、表示されていたコメントが消え、ファイル（JSON）からも削除されること。

## 5. 対象外 (Out of Scope)
- コメント内での Markdown レンダリング（今回はプレーンテキスト表示のみ）。
- コメント表示 Inlay 上に直接「対応済み (Resolved)」にするためのチェックボックス等を配置すること（ステータス変更はクリック後の編集パネルなどを経由する）。
