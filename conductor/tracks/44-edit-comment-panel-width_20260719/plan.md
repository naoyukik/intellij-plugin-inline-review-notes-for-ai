## Phase 1: 編集時の初期幅を統一する

- [ ] Task: 編集時の初期幅を定義する失敗テストを追加する
  - [ ] 編集時に、パネルを開く時点のエディタペイン幅の 60% が適用されることを検証するテストを追加する。
  - [ ] 新規作成時の幅計算が変更されないことを検証する既存テストを確認または追加する。
  - [ ] テストを実行し、修正前に失敗することを確認する。
- [ ] Task: 編集時の初期幅設定を実装する
  - [ ] 調査で特定した最小の実装箇所で、編集時にも新規作成時と同じ初期幅計算を適用する。
  - [ ] パネル表示後のエディタペインリサイズで、パネル幅を変更しない既存動作を維持する。
  - [ ] テキスト行数に応じた既存の高さ計算を維持する。
  - [ ] 関連テストを実行して Green を確認し、必要最小限のリファクタリング後に再実行する。
- [ ] Task: 品質検証と実装コミットを行う
  - [ ] 変更範囲のテスト、`./gradlew test`、利用可能な静的解析を実行する。

  - [ ] 成功後に実装変更をコミットし、コミット SHA を `plan.md` の完了タスクへ記録する。
  - [ ] 計画更新を別コミットにする。
