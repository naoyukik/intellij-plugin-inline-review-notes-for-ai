# Issue 44: 編集時のコメント入力パネル幅を新規作成時と統一する

## 概要

編集時の Inline Review Notes エディタパネルがエディタ幅の 60% で表示されない不具合を修正する。新規作成と編集の両方で、初期表示時および表示中のエディタペインリサイズ時に、エディタペイン幅の 60% をパネル幅へ適用する。

## 機能要件

- 新規作成時と編集時の両方で、パネルを開く時点のエディタペイン幅の 60% をパネル幅に設定する。
- パネルが開いている間にエディタペインの幅が変わった場合、表示中のパネル幅を同じ計算式で更新する。
- 既存のテキスト行数に応じたパネル高さの計算と表示動作は変更しない。

## 非機能要件

- 変更範囲をコメント入力パネルの表示サイズに限定する。
- コメントの入力、保存、編集、削除の既存動作を変更しない。
- Kotlin/IntelliJ Platform の既存設計とテスト方式に従う。

## 受け入れ基準

- 新規作成時と編集時のパネル幅は、開いた時点のエディタペイン幅の 60% で表示される。
- 新規作成時と編集時の両方で、パネル表示後にエディタペインをリサイズすると、パネル幅はリサイズ後のエディタペイン幅の 60% に更新される。
- 初期表示時およびリサイズ後のパネル幅は、最小 300px、最大 800px の既存制限を満たす。
- テキストの改行数に応じたパネル高さの既存動作が維持される。
- 上記を検証するテストが追加または更新される。

## 対象外

- 幅または高さの計算式そのものの再設計。
- コメントデータモデル、保存形式、保存処理の変更。
