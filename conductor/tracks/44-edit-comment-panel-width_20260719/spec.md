# Issue 44: 編集時のコメント入力パネル幅を新規作成時と統一する

## 概要

編集時の Inline Review Notes エディタパネルが小さい固定幅で表示される不具合を修正する。新規作成時の現行動作を変更せず、編集時の初期表示幅を IntelliJ のエディタペイン幅の 60% にする。パネルの表示後は、エディタペインをリサイズしてもパネル幅を変更しない。

## 機能要件

- 新規作成時の Inline Review Notes エディタパネルの幅計算と表示動作は現状のまま維持する。
- 編集時は、パネルを開く時点のエディタペイン幅の 60% をパネル幅に設定する。
- パネルが開いている間にエディタペインの幅が変わっても、表示中のパネル幅は変更しない。
- 既存のテキスト行数に応じたパネル高さの計算と表示動作は変更しない。

## 非機能要件

- 変更範囲をコメント入力パネルの表示サイズに限定する。
- コメントの入力、保存、編集、削除の既存動作を変更しない。
- Kotlin/IntelliJ Platform の既存設計とテスト方式に従う。

## 受け入れ基準

- 新規作成時のパネル幅は、変更前の実装と同じくエディタペイン幅の 60% で表示される。
- 編集時のパネル幅は、開いた時点のエディタペイン幅の 60% で表示される。
- 新規作成時と編集時の両方で、パネル表示後にエディタペインをリサイズしても、パネル幅は変わらない。
- テキストの改行数に応じたパネル高さの既存動作が維持される。
- 上記を検証するテストが追加または更新される。

## 対象外

- パネル表示後のエディタペイン幅変更への追従。
- 幅または高さの計算式そのものの再設計。
- コメントデータモデル、保存形式、保存処理の変更。
